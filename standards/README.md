# VERIDIC Standards

This directory holds VERIDIC's open standards. 

## Evidence Envelope Specification (EES)

An open format for recording the execution of consequential actions by AI agents as structured, tamper-evident, independently verifiable records. It defines the AgentInteractionRecord schema, the four-step verification algorithm, and the writer interface contract.

| Version | Status | Specification |
| --- | --- | --- |
| v0.1 | Published — stable | [Read the specification](https://theveridic.github.io/VERIDIC/standards/ees/v0.1/) |
| v0.2 | In development | [Markdown source](ees/v0.2/ees.md) and [draft AIR JSON Schema](ees/v0.2/air.schema.json) committed; worked examples and finalised schema to follow |

Published versions are not modified after release. Corrections and extensions are made in the next version.

## Standards track

Companion Internet-Draft: [draft-emirdag-scitt-ai-agent-execution-00](https://datatracker.ietf.org/doc/draft-emirdag-scitt-ai-agent-execution/) (IETF Datatracker) — the SCITT profile binding EES records to COSE/SCITT.
